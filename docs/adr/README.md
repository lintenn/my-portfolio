# Architecture Decision Records

Short documents that capture an important decision, its context and its consequences, so future readers (including future me) know _why_ the code looks the way it does. Format: [Michael Nygard's ADR template](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions). ADRs are immutable once accepted; a later decision _supersedes_ an earlier one.
